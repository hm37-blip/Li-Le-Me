# TabBar 图标说明

## 图标规格
- 尺寸：81x81 像素
- 格式：PNG
- 图标颜色：
  - 未选中：灰色 (#7A7E83)
  - 选中：橙色 (#FFA116)

## 所需图标

### 主页 (Home)
- `home.png` - 未选中状态（灰色）
- `home-active.png` - 选中状态（橙色）

### 趋势 (Trend)
- `trend.png` - 未选中状态（灰色）
- `trend-active.png` - 选中状态（橙色）

### 我的 (Profile)
- `profile.png` - 未选中状态（灰色）
- `profile-active.png` - 选中状态（橙色）

## 临时方案

当前使用的是 base64 编码的简单图标占位符。
建议使用专业设计工具（如 Figma、Sketch）或图标库（如 iconfont）制作正式图标。

## 推荐图标库
- iconfont (https://www.iconfont.cn/)
- Font Awesome
- Material Icons
