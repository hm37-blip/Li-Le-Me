## 📊 图表配置详情

### 折线图配置

```javascript
{
  color: ['#FFA116'],                // LeetCode橙
  grid: { ... },                     // 图表边距
  tooltip: { ... },                  // 触摸提示
  xAxis: { type: 'category' },      // 日期轴
  yAxis: { type: 'value' },         // 数值轴
  series: [{
    type: 'line',
    smooth: false,                   // 不平滑
    areaStyle: {                     // 渐变填充
      color: {
        type: 'linear',
        colorStops: [
          { offset: 0, color: 'rgba(255,161,22,0.3)' },
          { offset: 1, color: 'rgba(255,161,22,0.05)' }
        ]
      }
    }
  }]
}
```

### 饼图配置

```javascript
{
  color: ['#91CB74', '#FFA116', '#EF4743'],  // 简单/中等/困难
  legend: {
    orient: 'vertical',
    right: 10,
    formatter: (name) => `${name} ${percent}%`  // 动态百分比
  },
  series: [{
    type: 'pie',
    radius: ['45%', '70%'],          // 环形
    center: ['35%', '50%'],          // 偏左（为图例留空间）
    itemStyle: {
      borderRadius: 8,               // 圆角
      borderWidth: 2
    }
  }]
}
```

## 🔌 API 接口对接

### 当前状态

✅ **已准备好**:
- API 封装函数已完成
- 数据格式已定义
- 切换代码已写好（仅需取消注释）

⏳ **等待中**:
- 后端 B 提供云函数接口地址
- 后端 B 实现接口逻辑

### 需要后端提供的接口

**核心接口**:
```
GET /api/user/report?lcId={lcId}&range={week|month|year}
```

**返回格式**:
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "totalSolved": 256,
    "consecutiveDays": 12,
    "difficulty": {
      "easy": 120,
      "medium": 100,
      "hard": 36
    }
  }
}

注意: 历史趋势数据通过 `/api/v1/stats/trend` 接口单独获取：
{
  "dates": ["03-22", "03-23", "03-24", ...],
  "daily_points": [2, 5, 1, 4, 3, ...],
  "average_line": 3.29
}
```

详细定义请查看 `docs/API接口文档.md`

### 对接步骤

1. 修改 `utils/api.js` 第 5 行的 `BASE_URL`
2. 打开 `pages/report/report.js`
3. 在 `loadUserData()` 方法中：
   - 注释掉第 119-133 行（模拟数据）
   - 取消注释第 100-117 行（真实API）
4. 测试验证
