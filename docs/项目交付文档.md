## 当前技术栈

### 前端

- 微信小程序
- 原生 WXML/WXSS/JavaScript
- ECharts 小程序组件
- 自定义 tabbar
- 统一 API 封装：`frontend/utils/api.js`

### 后端

- Java 21
- Spring Boot 3.2
- MyBatis-Plus
- MySQL 8.0
- JWT access token + refresh token

## 已集成功能

### 用户与登录

- 微信登录：`POST /api/v1/user/login`
- JWT 登录态返回：`token`、`refreshToken`、`expiresIn`
- Token 刷新：`POST /api/v1/auth/refresh`
- 用户状态查询：`GET /api/v1/user/status`
- 绑定 LeetCode：`POST /api/v1/user/bind`
- 用户资料更新：`POST /api/user/profile`
- 注销账号：`DELETE /api/user/account`

### 战队

当前统一后的用户侧接口：

- 创建战队：`POST /api/v1/squad/create`
- 校验邀请码：`POST /api/v1/squad/verify`
- 加入战队并设置昵称/头像：`POST /api/v1/user/squad/join`
- 查询战队成员：`GET /api/v1/user/squad-members`

旧接口 `/api/squad/create`、`/api/squad/join` 已移除。

### 排行榜

- 每日战队排行榜：`GET /api/v1/rank/daily`
- 前端首页已请求真实接口，不再使用 `/api/ranking` 假数据接口
- 返回项包含 `rankTier`，前端首页不再显示固定 `-`

### 战报与数据可视化

- 用户报告：`GET /api/user/report`
- 用户信息：`GET /api/user/info`
- 趋势数据：`GET /api/v1/stats/trend`
- 难度分布：`GET /api/v1/stats/distribution`
- 365 天趋势按月汇总
- 后端趋势接口补齐缺失日期，前端仍保留补 0 兜底
- ECharts 已内置在 `frontend/components/ec-canvas/echarts.min.js`

### 分享

- 分享海报数据：`GET /api/v1/stats/poster`
- 海报图片：`GET /api/v1/stats/poster/image`
- 首页分享入口已接入海报生成和文案复制

### 后台管理

- 管理员战队 CRUD 和成员管理接口仍位于 `/api/admin/...`
- 前端管理员入口仍有硬编码口令，属于后续安全加固项

## 已知限制

1. 头像没有真正文件上传服务  
   当前只把小程序选择到的头像路径作为 `avatar_url` 存入后端。后续需要接云存储或文件上传接口。

2. 管理员入口安全性不足  
   `registration.js` 仍有前端硬编码管理员口令，应改成后端鉴权。

3. Debug 接口仍在普通 profile 下注册  
   `/debug/*` 适合开发阶段，生产部署前应加 profile 限制或移除。

4. 部分后台管理请求未接统一 API 封装  
   普通用户链路已统一到 `utils/api.js`，后台管理页仍保留独立 `wx.request`。

5. 小程序项目根目录敏感  
   必须打开 `frontend/` 目录，否则 `/static/...` 和 `/components/...` 路径会失效。

## 后续建议

- 后端增加头像/文件上传能力
- 管理员认证改为后端权限校验
- 为核心接口补充单元测试或集成测试数据
- 生产部署前关闭或隔离 `/debug/*`
- 清理旧页面 `frontend/pages/home` 与 `frontend/pages/index/home` 的功能重复关系
