### 图表配置


### 切换到真实API

1. 打开 `utils/api.js`
2. 修改 `BASE_URL` 为B提供的云函数地址：
   ```javascript
   const BASE_URL = 'https://your-actual-api.com'
   ```

3. 打开 `pages/report/report.js`
4. 找到 `loadUserData()` 方法
5. **注释掉** 模拟数据部分（第119-133行）
6. **取消注释** 真实API调用部分（第100-117行）

代码示例：

```javascript
async loadUserData() {
  wx.showLoading({ title: '加载中...' })

  try {
    // ========== 真实API调用 ==========
    const data = await api.getUserReport(this.data.lcId, this.data.timeRange)

    this.setData({
      totalSolved: data.totalSolved,
      consecutiveDays: dataHelper.calculateConsecutiveDays(data.historyLogs),
      easyCount: data.difficulty.easy,
      mediumCount: data.difficulty.medium,
      hardCount: data.difficulty.hard
    })

    this.updateLineChart(data.historyLogs)
    this.updatePieChart(data.difficulty)

    // ========== 模拟数据（注释掉） ==========
    // const mockData = this.getMockData()
    // ...

  } catch (error) {
    console.error('加载数据失败:', error)
    wx.showToast({ title: '加载失败', icon: 'error' })
  } finally {
    wx.hideLoading()
  }
}
```

## 🐛 常见问题

### Q1: 图表不显示？

**解决方法：**
1. 检查 `echarts.min.js` 是否下载到正确位置
2. 检查微信开发者工具的基础库版本 >= 2.9.0
3. 查看控制台是否有报错

### Q2: 模拟器显示正常，真机不显示？

**解决方法：**
1. 清除缓存重新编译
2. 检查真机微信版本
3. 查看真机调试控制台

### Q3: 想修改图表样式？

**参考：**
- ECharts 官方文档：https://echarts.apache.org/zh/option.html
- 在 `getLineChartOption()` 和 `getPieChartOption()` 方法中修改

### Q4: 数据格式不对？

**检查：**
- 后端返回的数据格式是否符合 `docs/API接口文档.md` 中的定义
- `historyLogs` 数组是否包含 `date` 和 `count` 字段
- `difficulty` 对象是否包含 `easy`, `medium`, `hard` 字段
