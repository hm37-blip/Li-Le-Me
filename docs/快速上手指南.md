# 力了么快速上手指南

本文档对应当前 `master-dev` 集成状态。项目已经接入 Java 后端、MySQL、ECharts、JWT/refresh token、排行榜、战报、分享海报和用户资料接口，不再需要切换模拟数据或手动下载 ECharts。

## 环境要求

- Java 21
- MySQL 8.0
- Node.js 20.x，用于前端 JavaScript 语法检查
- 微信开发者工具，基础库建议 >= 2.9.0

## 启动后端

后端目录是 `backend/`，默认连接本机 MySQL：

```bash
cd backend
JAVA_HOME=/opt/homebrew/opt/openjdk@21 PATH=/opt/homebrew/opt/openjdk@21/bin:$PATH ./mvnw spring-boot:run
```

测试/编译：

```bash
cd backend
JAVA_HOME=/opt/homebrew/opt/openjdk@21 PATH=/opt/homebrew/opt/openjdk@21/bin:$PATH ./mvnw clean test
```

当前后端技术栈：

- Spring Boot 3.2
- MyBatis-Plus
- MySQL 8.0
- JWT access token + refresh token

## 打开小程序

用微信开发者工具打开 `frontend/` 目录，而不是仓库根目录。项目里的图片、组件和 tabbar 使用小程序根路径，例如 `/static/images/...`、`/components/...`，打开错误目录会导致路径找不到。

开发阶段需要在微信开发者工具里开启：

- 不校验合法域名、web-view、TLS 版本以及 HTTPS 证书

前端默认后端地址在 `frontend/utils/api.js`：

```javascript
const BASE_URL = 'http://localhost:8080'
```

## ECharts

`frontend/components/ec-canvas/echarts.min.js` 已经包含在当前代码中，不需要手动下载。相关页面可直接使用：

- `frontend/pages/index/report/report`

如果图表不显示，优先检查：

- 是否打开的是 `frontend/` 目录
- 微信基础库版本是否满足要求
- 控制台是否有 canvas 或组件路径错误

## 当前主要功能

- 微信登录：`POST /api/v1/user/login`
- Token 刷新：`POST /api/v1/auth/refresh`
- 绑定 LeetCode：`POST /api/v1/user/bind`
- 查询用户状态：`GET /api/v1/user/status`
- 邀请码校验：`POST /api/v1/squad/verify`
- 加入战队：`POST /api/v1/user/squad/join`
- 创建战队：`POST /api/v1/squad/create`
- 每日排行榜：`GET /api/v1/rank/daily`
- 用户报告：`GET /api/user/report`
- 用户信息：`GET /api/user/info`
- 趋势数据：`GET /api/v1/stats/trend`
- 难度分布：`GET /api/v1/stats/distribution`
- 分享海报：`GET /api/v1/stats/poster`
- 资料更新：`POST /api/user/profile`
- 注销账号：`DELETE /api/user/account`

详细参数和返回格式见 `docs/API接口文档.md`。

## 前端检查

```bash
find frontend -name '*.js' -print0 | xargs -0 -n1 node --check
```

目前普通用户链路请求已经统一走 `frontend/utils/api.js`，它负责 Bearer token、401 refresh 和重试。登录页仍直接调用登录接口，后台管理页仍保留独立请求逻辑。

## 常见问题

### 后端测试连不上 MySQL

确认 MySQL 8.0 已启动，且 `backend/src/main/resources/application.yml` 中的账号密码与本机一致。

### 小程序图片或组件加载失败

确认微信开发者工具打开的是 `frontend/`。如果打开仓库根目录，绝对路径会错。

### 分享海报无法预览

本地开发时海报 URL 指向 `http://localhost:8080/api/v1/stats/poster/image?...`。真机调试时需要手机能够访问后端地址，或改成可访问的局域网/线上地址。

### 头像上传为什么还是本地路径

当前后端资料接口只持久化 `avatar_url` 字符串，没有文件上传服务。小程序选择头像后会把路径写入后端；跨设备稳定显示头像需要后续接云存储或文件上传接口。
