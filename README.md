# 力了么 — 账号与社交模块

---

## 项目简介

**力了么**（LeetCode 了么）是一款微信小程序，帮大家互相督促刷 LeetCode。用户通过微信登录后绑定自己的 LeetCode 账号，加入战队，一起追踪刷题进度。

这个分支负责的是**账号与社交模块**，解决两件事：

- **我是谁** — 登录注册、个人资料、LeetCode 绑定
- **我在哪个圈子** — 战队加入、邀请码机制、好友分享

---

## 技术栈

| 层级     | 技术                                              |
| -------- | ------------------------------------------------- |
| 前端     | 微信小程序（原生开发）                            |
| 后端     | Spring Boot                                       |
| 用户认证 | 微信 OAuth（`wx.login()` → `js_code` → `openid`） |
| 文件存储 | 微信云存储（头像上传）                            |
| 社交分享 | 微信 `onShareAppMessage` API                      |

---

## 用户流程

```
微信登录 (wx.login)
        |
        v
  registration_status?
        |
        +-- 0 (全新用户) --> 设置头像和昵称 --> 绑定 LeetCode --> 进入首页
        |
        +-- 1 (资料已填) --> 绑定 LeetCode --> 进入首页
        |
        +-- 2 (老用户)   --> 直接进入首页
                                |
                                v
                        输入邀请码加入战队
                                |
                                v
                        开始刷题 / 分享邀请卡给好友
```

## 接口定义

### 微信授权登录 — `WechatLogin`

用户打开小程序时调用 `wx.login()` 拿到 `js_code`，发给后端换取身份信息。

**输入：**

| 参数      | 类型   | 说明                 |
| --------- | ------ | -------------------- |
| `js_code` | String | 从 `wx.login()` 获得 |

**输出：**

| 参数                  | 类型    | 说明             |
| --------------------- | ------- | ---------------- |
| `openid`              | String  | 用户唯一标识     |
| `is_new_user`         | Boolean | 是否为新用户     |
| `token`               | String  | 登录凭证         |
| `registration_status` | Int     | 注册状态，见下方 |

`registration_status` 含义：

| 值  | 含义                      | 前端跳转     |
| --- | ------------------------- | ------------ |
| `0` | 全新用户                  | → 填写资料页 |
| `1` | 已填资料，未绑定 LeetCode | → 绑定页     |
| `2` | 完整用户                  | → 首页       |

---

### 设置头像和昵称 — `UpdateUserProfile`

新用户注册后第一步。头像先传到微信云存储，拿到路径后再调这个接口。

**输入：**

| 参数             | 类型   | 说明                         |
| ---------------- | ------ | ---------------------------- |
| `openid`         | String | 用户标识                     |
| `user_nickname`  | String | 昵称                         |
| `avatar_file_id` | String | 上传到云存储后返回的图片路径 |

**输出：**

| 参数                     | 类型    | 说明         |
| ------------------------ | ------- | ------------ |
| `profile_update_success` | Boolean | 是否更新成功 |

---

### LeetCode 账号绑定 — `LeetCodeBind`

用户输入自己的 LeetCode 用户名。后端需要**实时校验**该 ID 在 leetcode.com 上是否存在且公开可见。

**输入：**

| 参数                | 类型   | 说明            |
| ------------------- | ------ | --------------- |
| `openid`            | String | 用户标识        |
| `leetcode_username` | String | LeetCode 用户名 |

**输出：**

| 参数              | 类型    | 说明                        |
| ----------------- | ------- | --------------------------- |
| `LC_bind_success` | Boolean | 是否绑定成功                |
| `error_message`   | String  | 失败原因，例如 `"ID不存在"` |

---

### 战队生成 — `SquadGenerate`

> 后台管理接口，仅开发团队使用，不对外暴露。

**输入：**

| 参数          | 类型   | 说明                        |
| ------------- | ------ | --------------------------- |
| `squad_name`  | String | 战队名称                    |
| `invite_code` | String | 邀请码                      |
| `admin_id`    | String | 管理员 ID（设置给开发成员） |
| `max_members` | Int    | 最大成员数（暂定 50）       |

**输出：**

| 参数         | 类型      | 说明                  |
| ------------ | --------- | --------------------- |
| `squad_id`   | String    | 战队 ID               |
| `created_at` | Timestamp | 创建时间              |
| `is_active`  | Boolean   | `true` 表示战队可加入 |

---

### 战队加入（受邀制）— `VerifyInviteCode`

用户必须输入邀请码才能加入战队。

**输入：**

| 参数          | 类型   | 说明     |
| ------------- | ------ | -------- |
| `openid`      | String | 用户标识 |
| `invite_code` | String | 邀请码   |

**输出：**

| 参数                 | 类型    | 说明                          |
| -------------------- | ------- | ----------------------------- |
| `squad_join_success` | Boolean | 是否加入成功                  |
| `squad_name`         | String  | 战队名称                      |
| `error_msg`          | String  | 失败原因，例如 `"邀请码错误"` |

---

### 分享裂变 — `ShareInviteID`

通过微信 `onShareAppMessage` API 生成带邀请码的分享卡片。好友点开卡片后邀请码自动填入，点确认就会触发 `VerifyInviteCode` 完成加入。

**输入：**

| 参数            | 类型   | 说明       |
| --------------- | ------ | ---------- |
| `invite_code`   | String | 邀请码     |
| `user_nickname` | String | 分享者昵称 |

**输出：**

| 参数          | 类型   | 说明                                          |
| ------------- | ------ | --------------------------------------------- |
| `invite_code` | String | 传给新用户，确认后自动调用 `VerifyInviteCode` |

---

### 更换头像 — `UpdateUserAvatar`

**输入：**

| 参数                 | 类型   | 说明               |
| -------------------- | ------ | ------------------ |
| `openid`             | String | 用户标识           |
| `new_avatar_file_id` | String | 新头像的云存储路径 |

**输出：**

| 参数                    | 类型    | 说明         |
| ----------------------- | ------- | ------------ |
| `update_avatar_success` | Boolean | 是否更新成功 |

---

### 销号 — `DeleteUserAccount`

**输入：**

| 参数     | 类型   | 说明     |
| -------- | ------ | -------- |
| `openid` | String | 用户标识 |

**输出：**

| 参数                  | 类型    | 说明         |
| --------------------- | ------- | ------------ |
| `delete_user_success` | Boolean | 是否删除成功 |
