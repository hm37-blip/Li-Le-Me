## 这个分支做什么？

这个分支负责整个 **账号与社交模块（Account & Squad）**，核心要解决两个问题：

- **"我是谁"** — 用户注册、登录、个人资料管理
- **"我在哪个圈子"** — 战队创建、邀请加入、分享裂变

---

## 技术栈

| 层级     | 技术                                              |
| -------- | ------------------------------------------------- |
| 前端     | 微信小程序（原生开发）                            |
| 后端     | Spring Boot                                       |
| 用户认证 | 微信 OAuth（`wx.login()` → `js_code` → `openid`） |
| 文件存储 | 微信云存储（头像上传）                            |
| 社交分享 | 微信 `onShareAppMessage` API                      |

## 接口定义

### F1.1 微信授权登录 — `WechatLogin`

用户打开小程序时调用 `wx.login()` 获取 `js_code`，发送给后端换取身份信息。

**输入：**

| 参数      | 类型   | 说明                 |
| --------- | ------ | -------------------- |
| `js_code` | String | 从 `wx.login()` 获得 |

**输出：**

| 参数                  | 类型    | 说明               |
| --------------------- | ------- | ------------------ |
| `openid`              | String  | 用户唯一标识       |
| `is_new_user`         | Boolean | 是否为新用户       |
| `token`               | String  | 登录凭证           |
| `registration_status` | Int     | 注册状态（见下方） |

**`registration_status` 状态码：**

| 值  | 含义                      | 前端行为         |
| --- | ------------------------- | ---------------- |
| `0` | 全新用户                  | 跳转到填写资料页 |
| `1` | 已填资料，未绑定 LeetCode | 跳转到绑定页     |
| `2` | 完整用户                  | 直接进入首页     |

---

### F1.1.1 上传头像和昵称 — `UpdateUserProfile`

新用户注册后设置个人资料。头像先上传到微信云存储，拿到文件路径后再调用此接口。

**输入：**

| 参数             | 类型   | 说明                             |
| ---------------- | ------ | -------------------------------- |
| `openid`         | String | 用户标识                         |
| `user_nickname`  | String | 昵称                             |
| `avatar_file_id` | String | 用户上传到云存储后返回的图片路径 |

**输出：**

| 参数                     | 类型    | 说明         |
| ------------------------ | ------- | ------------ |
| `profile_update_success` | Boolean | 是否更新成功 |

---

### F1.2 LeetCode ID 绑定 — `LeetCodeBind`

用户输入自己的 LeetCode 用户名，后端需要**实时校验**该 ID 在 leetcode.com 上是否存在且公开可见。

**输入：**

| 参数                | 类型   | 说明            |
| ------------------- | ------ | --------------- |
| `openid`            | String | 用户标识        |
| `leetcode_username` | String | LeetCode 用户名 |

**输出：**

| 参数              | 类型    | 说明                        |
| ----------------- | ------- | --------------------------- |
| `LC_bind_success` | Boolean | 是否绑定成功                |
| `error_message`   | String  | 失败原因，例如 `"ID不存在"` |

---

### F1.3 战队生成 — `SquadGenerate`

> 此接口为**后台管理接口**，仅开发团队使用，不对外暴露。

**输入：**

| 参数          | 类型   | 说明                        |
| ------------- | ------ | --------------------------- |
| `squad_name`  | String | 战队名称                    |
| `invite_code` | String | 邀请码                      |
| `admin_id`    | String | 管理员 ID（设置给开发成员） |
| `max_members` | Int    | 最大成员数（暂定 50）       |

**输出：**

| 参数         | 类型      | 说明                    |
| ------------ | --------- | ----------------------- |
| `squad_id`   | String    | 战队 ID（后台信息）     |
| `created_at` | Timestamp | 创建时间                |
| `is_active`  | Boolean   | `true` 表示战队仍可加入 |

---

### F1.3.1 战队加入（受邀制）— `VerifyInviteCode`

用户必须输入特定的邀请码才能加入战队。

**输入：**

| 参数          | 类型   | 说明     |
| ------------- | ------ | -------- |
| `openid`      | String | 用户标识 |
| `invite_code` | String | 邀请码   |

**输出：**

| 参数                 | 类型    | 说明                          |
| -------------------- | ------- | ----------------------------- |
| `squad_join_success` | Boolean | 是否加入成功                  |
| `squad_name`         | String  | 战队名称                      |
| `error_msg`          | String  | 失败原因，例如 `"邀请码错误"` |

---

### 分享裂变 — `ShareInviteID`

通过微信自带的 `onShareAppMessage` API 生成带有邀请码的微信分享卡片。好友点击卡片后，邀请码自动填入，确认即可触发 `VerifyInviteCode` 完成加入。

**输入：**

| 参数            | 类型   | 说明       |
| --------------- | ------ | ---------- |
| `invite_code`   | String | 邀请码     |
| `user_nickname` | String | 分享者昵称 |

**输出：**

| 参数          | 类型   | 说明                                                      |
| ------------- | ------ | --------------------------------------------------------- |
| `invite_code` | String | 邀请码（传递给新用户，确认后自动调用 `VerifyInviteCode`） |

---

## 用户流程

```
微信登录 (wx.login)
      |
      v
 registration_status?
      |
      +-- 0 (全新用户) --> 填写资料 (头像+昵称) --> 绑定 LeetCode --> 首页
      |
      +-- 1 (已填资料) --> 绑定 LeetCode --> 首页
      |
      +-- 2 (完整用户) --> 首页
                            |
                            v
                    输入邀请码加入战队
                            |
                            v
                   开始刷题 / 分享邀请卡片给好友
```
